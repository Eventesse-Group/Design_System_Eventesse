# Referência para Penpot

O Penpot deve espelhar os nomes dos tokens CSS, removendo o prefixo `--eds-` e convertendo níveis em grupos. Exemplo: `operational/brand`, `operational/line` e `operational/control-height`.

## Componentes principais

Brand, Button, Status Badge, Sidebar, Page Header, Metric Strip, Toolbar, Data Table, Pagination e Side Panel.
